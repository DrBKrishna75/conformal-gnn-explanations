# Conformal Explanation Sets for Graph Neural Networks under Structural Distribution Shift: Coverage and Risk Control

Code and result files for the manuscript submitted to *Knowledge-Based Systems*
(B. Krishna, T. R. Srinivas, M. A. Rahman, Neil Gogte Institute of Technology, Hyderabad, India).

## Environment

Python 3.11, PyTorch 2.14.1, PyTorch Geometric 2.8.0, NumPy, scikit-learn (see `requirements.txt`).
The main comparisons (Weeks 16-23) run on the CPU with deterministic algorithms and fixed seeds.
Earlier exploratory runs (Weeks 1-15) used a GPU and are not bit-reproducible.

## Data

* Synthetic graphs (BA-Shapes, BA-Cycles, BA-Grids, Tree-Cycles, Tree-Grids) are generated by the scripts.
* Cora and CiteSeer: Planetoid versions distributed with PyTorch Geometric.
* Twitch: download `twitch.zip` from https://snap.stanford.edu/data/twitch.zip and extract it to `E:\data\twitch`.

Paths in the scripts (`E:\data`, `E:\results`) can be changed at the top of each file.
The `results` folder contains the JSON output of every script.
